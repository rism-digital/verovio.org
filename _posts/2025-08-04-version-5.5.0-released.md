The 5.5 release brings a new binding to Swift, which is distributed via the Swift Package Manager. This makes Verovio very easy to include and use in iOS applications. See the Reference book [documentation](https://book.verovio.org/installing-or-building-from-sources/swift-and-objective-c.html#swift) for details on how to use the Swift binding.

Another new feature of 5.5 is the option to use the Liberation text font, which can be embedded or linked to in the SVG. This improves the rendering of text on platforms where Times or Times New Roman is not available by default, such as Android.
