The release 6.3 of Verovio brings a range of new features, rendering improvements, and bug fixes. It adds support for `volta` and `refrain`, and of `pt` and `vu` support for MEI font sizes. Turkish accidentals have been added, as well as a new `--show-hidden` option for displaying hidden elements. 

The experimental editor API has been updated, alongside various improvements to the MusicXML importer. The Python build process has also been fully updated.
