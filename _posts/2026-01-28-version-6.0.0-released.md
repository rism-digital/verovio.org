Release 6.0 is the first release of 2026, and it introduces several important new features. One of the highlights is support for ossia staves and ossia staff groups, which can now be placed above or below a staff. A set of new options makes it possible to control their appearance.

Verovio now processes repetitions (that is, expansions) by default when the output format is MIDI or a time map. The same behavior has been added to the MusicXML importer (thanks to @infojunkie). Bear this in mind when upgrading your system if you rely on the MIDI and the time map output. This default can be overridden using newly introduced, dedicated options.
