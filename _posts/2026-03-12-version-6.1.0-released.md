The release 6.1 of Verovio is the first to use the development version of the MEI Schema since MEI 5.1. This means that upcoming features of MEI will now start to be implemented in Verovio. This is the case for staff-like tablature notation, for which initial support has been added (thanks to @paul-bayleaf).

In addition to improvements to the rendering (key signatures, mixed beams) and to some importers (MusicXML and CMME), this release also integrates support for ASCL custom tuning, implemented by @info-junkie. This does not represent a core feature, as it essentially targets the MIDI output, but it might be of interest to some users.
