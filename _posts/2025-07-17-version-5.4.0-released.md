The 5.4 release includes several small improvements and fixes. The time map and MIDI output have been corrected for measure rests, particularly in the case of upbeat measures. Another update involves changes to the key names in the JSON output when retrieving time information for certain elements in the time map.

A notable change is the reduction of the initial memory allocation in the JavaScript toolkit. This significantly lowers Verovio's memory usage in most cases, which will be especially beneficial on less powerful devices. It should not affect the loading of large files — the original reason for the higher memory allocation — but that level of allocation is no longer necessary. As a result, the `verovio-toolkit-light` version, which offered a lower memory footprint, is no longer provided.
